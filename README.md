# HAMO DOOR TECH

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose + Material 3) للفنيين العاملين على صيانة الأبواب والبوابات الأوتوماتيك. عربي بالكامل (RTL)، يعمل دون إنترنت، وكل البيانات محلية على الجهاز.

## المتطلبات والبناء
- JDK 17، وAndroid SDK (compileSdk 35، الحد الأدنى Android 8.0 / API 26).
- البناء: `./gradlew assembleDebug` ← الناتج `app/build/outputs/apk/debug/app-debug.apk`
- الاختبارات: `./gradlew testDebugUnitTest`
- يبني GitHub Actions المشروع عند كل push وينشر ملف APK تجريبي في صفحة Releases.

## البنية
MVVM بثلاث طبقات: `ui` (Compose + ViewModels)، `domain` (البحث، التطبيع العربي، التحقق)، `data` (Room + مستودع + نسخ احتياطي). الصور تُحفظ محليًا، وتقرير PDF يُنشأ بواجهة Android PdfDocument.

## الميزات المنفذة
- أنواع أبواب قابلة للتعديل، شركات، موديلات، أعطال (أعراض + أكواد + حلول + خطوات)، أدلة (تركيب/برمجة/توصيلات/ريموت)، قطع غيار، سجل زيارات صيانة، مفضلة، مكتبة مرفقات.
- إضافة/تعديل/نسخ/حذف لكل البيانات مع منع الحذف عند وجود ارتباطات.
- بحث محلي مع تطبيع عربي وتطابق جزئي وترتيب ومرشحات، وشاشة تشخيص تعرض مستوى توثيق المصدر وأن الأسباب محتملة وليست تشخيصًا مؤكدًا.
- صور من الكاميرا أو المعرض، ومرفقات ومستندات وروابط فيديو.
- تقرير زيارة PDF عربي (قبل/بعد) قابل للمشاركة.
- نسخ احتياطي ZIP (بصمات SHA-256) واستعادة بالدمج فقط، مع معاينة قبل التنفيذ ورفض الملفات التالفة.
- تحذيرات سلامة؛ ولا يقترح التطبيق تعطيل حساسات الأمان.

## البيانات التجريبية
بيانات تعليمية مميزة بوسم «تجريبي»: 7 أنواع أبواب، شركات وموديلات **وهمية** بأسماء تعليمية، 17 عطلًا عامًا، 11 دليلًا، 5 زيارات. هي إرشادات عامة **غير خاصة بأي شركة أو موديل**، ولا توجد فيها أكواد أعطال ولا قيم برمجة ولا مخططات توصيل مختلقة. يمكن حذفها من الإعدادات. المحتوى الخاص بكل موديل يجب أن يُدخله الفني من دليل الشركة المصنعة.

## الاختبارات (ما نُفِّذ فعلًا)
- اختبارات وحدة (Robolectric) تُشغَّل على GitHub Actions: CRUD والعلاقات وحماية الحذف، البحث والمرشحات، المفضلة، الزيارات، النسخ الاحتياطي والاستعادة والملفات التالفة، التحقق، البيانات التجريبية.
- اختبارا androidTest (فحص أساسي + إنشاء PDF) **تُجمَّع فقط ولم تُشغَّل** لعدم توفر محاكي. إنشاء PDF لم يُتحقق منه آليًا.
- لم يُجرَّب التطبيق على جهاز حقيقي؛ الكاميرا واختيار الصور وعرض الخط العربي في PDF تحتاج تجربة يدوية.

## حدود معروفة
- لا مزامنة سحابية ولا حسابات.
- محتوى الأعطال العام تعليمي ويجب مراجعة دليل الشركة قبل أي ضبط.
- الإصدار الحالي debug فقط (غير موقّع للنشر).
